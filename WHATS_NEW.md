## 🚀 How to Use

### Upload Data:
1. Open your project
2. Click **"Upload Data"** button
3. Select file type (Production or Financial)
4. Choose your CSV/XLSX file
5. Click **"Upload File"**

### View Analytics:
1. Open your project
2. Click **"Analytics"** button
3. See charts and visualizations
4. Monitor data quality

### Run Valuation:
1. Upload data files (optional - works with defaults too)
2. Go to **"Financial Modeling"**
3. Create assumptions
4. Create scenario
5. Click **"Run Valuation"**
6. View results with charts!
