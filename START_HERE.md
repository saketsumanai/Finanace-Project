- Production data (oil, gas, water volumes)
- Financial data (revenue, costs, cash flow)

- Well data (locations, status)
- Any CSV file with structured data

### How to Upload
```
1. Go to AI Chat
2. Click paperclip icon (📎)
3. Select CSV file (max 10 MB)
4. Click Send
5. Get AI analysis in 3-5 seconds
```

### What AI Analyzes
- Data structure (rows, columns, types)
- Numeric statistics (mean, median, min, max)
- Data quality (missing values, outliers)
- Data type identification
- Key patterns and trends
- Recommendations for valuation

## 🔧 Troubleshooting

### Issue: "Failed to get AI response"
**Most Common Cause:** Not logged in

**Solution:**
```
1. Make sure you're logged in
2. Go to http://localhost:5173/login
3. Login with your credentials
4. Try AI Chat again
```

### Issue: "Network Error"
**Cause:** Containers not running

**Solution:**
```bash
cd "/Users/saketsmac/Desktop/Finanace Project"
docker-compose restart
# Wait 30 seconds
# Try again
```

### Issue: "Token expired"
**Cause:** JWT token expired (24 hours)

**Solution:**
```
1. Logout
2. Login again
3. Continue working
```

### Issue: "CSV upload failed"
**Possible Causes:**
- Wrong file type (not CSV)
- File too large (> 10 MB)
- Invalid CSV format

**Solution:**
```
1. Make sure file is .csv format
2. Check file size (< 10 MB)
3. Open in Excel and save as CSV (UTF-8)
4. Try again
```
